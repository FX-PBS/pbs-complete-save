# About

This is a naturally raised save file for Senran Kagura: Peach Beach Splash (PBS). Feel free to use it.

# How to use

1. On Steam, go to your games library
2. Right click on PBS then select Manage -> Browse local files
3. Go to savedata folder, then go to a folder with a bunch of numbers. This folder corresponds to your Steam account, and gets synced with Steam Cloud
4. Download the savedata010.dat file from this repository, then paste it in there. This will show up as the 10th save in-game. If you want it to be your 1st save, or 2nd save, rename the file accordingly (e.g., savedata002.dat for 2nd save).
